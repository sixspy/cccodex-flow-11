## 双源合并

主份编排 + 次份编排先各自抽取成功，才准进入合并环节；合并收尾后再抽段，合并结果未收尾不准入库。

- **合并键**：后台按字段顺序以 `|` 拼接（如 `batch|row_id`），任一段空缺的行不入合并；键空缺不开跑。拼法与键预看在合并详情可核对。
- **冲突裁定**（预看同详情）：同键同字段值不同即为抵触行。
  - `整行败绩`：整条抵触行丢入冲突匣，主次份均不进合并结果。
  - `保主旁记`：保留主份值，冲突行旁记次份差。
- **策略钉死**：策略按日钉死，当日不得更换；点合并时的处置必须与策略一致，否则返回「冲突策略漂了」。
- **争抢合并**：`待合并 → 合并中` 原子抢占，只有先手成功，后手记为合并争用败绩并展示在详情。
- 双源列表展示主份计数、次份计数、冲突行数与冲突策略名；详情区分主份/次份、冲突行与冲突匣。
